# k6 Performance Scenarios

        These files are an optional benchmark boundary generated by AtlasCore.
        They add no Node dependency and do not change any API image.

        Generated scenarios:

        - `core-public`
- `core-protected`
- `core-gateway`
- `eventing-outbox`
- `notification-local`

        Run `make benchmark-k6-smoke K6_SCENARIO=<name>` first. Increase load
        only after smoke passes. Results are normalized into
        `.artifacts/benchmarks/` beside the native Atlas benchmark reports.

        The runner uses a locally installed `k6` binary when available and
        otherwise uses `grafana/k6:2.0.0` through `docker-compose.benchmark.yml`.

        Safety:

        - non-local targets are rejected unless explicitly authorized;
        - credentials come from `K6_AUTH_EMAIL` and `K6_AUTH_PASSWORD`;
        - Notification uses `example.invalid`, transient delivery and requires
          the `local_ack` provider;
        - raw Kafka throughput remains a separate Atlas benchmark.
